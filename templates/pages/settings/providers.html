About AI Providers

AutomatedPastor supports multiple AI providers. The Claude CLI is the default and requires no API key if you have Claude Code installed. API-based providers require an API key from their respective platforms.

  • Claude CLI - Uses the Claude Code CLI (default, no API key needed)
  • Claude API - Direct Anthropic API access
  • OpenAI - GPT models from OpenAI
  • Gemini - Google's Gemini models
